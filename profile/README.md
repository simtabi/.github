# We design software, brands, and the tools in between.

[Simtabi](https://simtabi.com) is a software design agency and design & branding
studio based in Delaware, USA and Nairobi, Kenya. Whenever we build something that
might be useful to others, we extract it and release it as open source. Everything
we publish lives at [opensource.simtabi.com](https://opensource.simtabi.com).

## What we build

- [laranail](https://github.com/laranail) — a family of Laravel packages for
  building, scaffolding, and shipping your own Laravel packages, plus the toolkit
  that grew around them.
- Developer tools — command-line utilities for everyday engineering work:
  - [probaci](https://github.com/simtabi/probaci) — prove your CI pipeline before
    you push, by running your CI checks locally in containers.
  - [osaat](https://github.com/simtabi/osaat) — audit and back up installed
    applications on macOS, Linux, and Unix.
  - [ssh-manager](https://github.com/simtabi/ssh-manager) — profile-based SSH key
    and config lifecycle manager.
  - [repoclone](https://github.com/simtabi/repoclone) — bulk-clone repositories
    from GitHub, GitLab, Bitbucket, and beyond.
- docsmith — the config-driven documentation platform behind
  [opensource.simtabi.com](https://opensource.simtabi.com).

## Get involved

- Found a bug or have an idea? Open an issue on the relevant repository — it
  beats email, and everyone benefits from the answer.
- Security disclosures: see our
  [security policy](https://github.com/simtabi/.github/blob/main/SECURITY.md) —
  please never use public issues for vulnerabilities.
- Anything else: [opensource@simtabi.com](mailto:opensource@simtabi.com).
